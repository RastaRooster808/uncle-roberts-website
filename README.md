# Uncle Robert's — Kalapana, Hawaiʻi

`main` is intentionally a stub. The actual draft site — built, deployed,
and awaiting Uncle Robert's family's review and approval — lives on the
[`proposal`](https://github.com/RastaRooster808/uncle-roberts-website/tree/proposal)
branch, not here.

Nothing merges into `main` until the family has reviewed `proposal` and
signed off. Once approved: merge `proposal` → `main`, restore
`public/CNAME` (set to `uncleroberts.website`), and point the GitHub
Pages deploy workflow's trigger back at `main`. See the `proposal`
branch's README for the full picture of what's real, what's still
placeholder, and what's deliberately not built yet.
